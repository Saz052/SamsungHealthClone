# Шаги — Android-трекер

Небольшое Android-приложение для подсчёта шагов, оценки времени ходьбы и просмотра истории за неделю. Это самостоятельный проект с собственным оформлением, неофициальное приложение Samsung.

## Возможности

- считает шаги аппаратным датчиком Android, в том числе при свёрнутом приложении;
- показывает шаги и активное время за день; время суммируется по непрерывным сигналам датчика шагов;
- приблизительно оценивает расстояние и расход энергии;
- хранит дневные итоги и активное время локально на устройстве;
- показывает историю за последние семь дней, включая активное время;
- открывает локальные тестовые настройки после пяти быстрых нажатий на заголовок «Шаги»;
- позволяет выбрать дату (сегодня или прошедший день) и задать для неё общее число шагов.

Активное время считается по интервалам между сигналами датчика шагов; паузы длиннее 10 секунд не учитываются. Расстояние и калории рассчитываются приблизительно по количеству шагов. Для сбора данных нужны датчик `TYPE_STEP_DETECTOR` и разрешение Android на распознавание активности. Ручные изменения влияют только на это приложение; прошедшее активное время ими не пересчитывается.

## Скачать APK через GitHub

1. Откройте репозиторий и вкладку **Actions**.
2. Выберите последний успешный запуск **Build Android APK**.
3. Скачайте artifact **stride-tracker-debug-apk** внизу страницы.
4. Распакуйте ZIP и установите `app-debug.apk` на Android. При необходимости разрешите установку приложений из выбранного файлового менеджера.

Push в ветку `main` или `master` автоматически запускает сборку. Используются Java 17, Gradle 8.6 и Android SDK 34.

## Локальная сборка

Нужны JDK 17, Gradle 8.6 и Android SDK Platform 34 / Build Tools 34.0.0:

```sh
gradle assembleDebug
```

APK появится в `app/build/outputs/apk/debug/app-debug.apk`.
