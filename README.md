# Шаги — Android-трекер

Лёгкое Android-приложение для подсчёта шагов, оценки времени ходьбы и просмотра истории за неделю. Это самостоятельный проект с собственным оформлением, неофициальное приложение Samsung.

## Возможности

- считает шаги аппаратным датчиком Android, в том числе при свёрнутом приложении;
- показывает шаги, примерное время ходьбы, расстояние и расход энергии;
- сохраняет дневную историю локально на устройстве;
- показывает итоги и столбчатую диаграмму за последние семь дней;
- содержит локальное скрытое меню для тестирования значений: пять быстрых нажатий на заголовок «Шаги».

Время, расстояние и калории оцениваются приблизительно по количеству шагов. Для фактического подсчёта требуется устройство с датчиком `TYPE_STEP_DETECTOR` и разрешение Android на распознавание активности. Изменения в скрытом меню сохраняются только локально и не изменяют данные других приложений или Samsung Health.

## Скачать APK через GitHub

1. Откройте репозиторий и вкладку **Actions**.
2. Выберите самый свежий успешный запуск **Build Android APK**.
3. Внизу страницы скачайте artifact **stride-tracker-debug-apk**.
4. Распакуйте ZIP и установите `app-debug.apk` на Android. При необходимости разрешите установку приложений из выбранного файлового менеджера.

Каждый push в `main` запускает сборку автоматически. Сборка использует GitHub Actions, Java 17, Gradle 8.6 и Android SDK 34.

## Локальная сборка

Нужны JDK 17, Gradle 8.6 и Android SDK Platform 34 / Build Tools 34.0.0:

```sh
gradle assembleDebug
```

Готовый файл появится в `app/build/outputs/apk/debug/app-debug.apk`.

## Структура

- `app/src/main/java/com/stride/tracker/` — экран приложения, сервис датчика шагов и локальное хранилище.
- `app/src/main/res/` — тема, название и значок уведомления.
- `.github/workflows/build.yml` — автоматическая сборка APK.
